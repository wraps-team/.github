# Support

Need help with Wraps? Here's how to get support.

## Documentation

Start with our docs — most questions are answered there:

- **[Getting Started](https://wraps.dev/docs/quickstart)** — Deploy your first email infrastructure
- **[SDK Reference](https://wraps.dev/docs/sdk)** — TypeScript SDK documentation
- **[CLI Reference](https://wraps.dev/docs/cli)** — CLI commands and options

## Community

- **[Discord](https://discord.gg/wraps)** — Chat with the team and community
- **[GitHub Discussions](https://github.com/wraps-team/wraps/discussions)** — Ask questions, share ideas

## Issues

Found a bug or have a feature request?

- **CLI issues** — [wraps-team/wraps/issues](https://github.com/wraps-team/wraps/issues)
- **SDK issues** — [wraps-team/wraps-js/issues](https://github.com/wraps-team/wraps-js/issues)

Before opening an issue:
1. Search existing issues to avoid duplicates
2. Include your CLI/SDK version (`wraps --version`)
3. Include relevant error messages and logs

## Security

Found a security vulnerability? Please report it privately via [GitHub Security Advisories](https://github.com/wraps-team/wraps/security/advisories/new) rather than opening a public issue.
